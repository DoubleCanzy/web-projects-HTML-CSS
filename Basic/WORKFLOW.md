# Basic 文件夹 · 工作流程说明

## 用途

本文件夹专门用于存放**基础前端小文档和小项目**（HTML / CSS / JavaScript 入门练习、小型演示页面等）。

## 指令格式（发给我新项目时的 prompt 规范）

每次发起新项目，请按以下格式提供信息，**文件夹名**和**内容**为必填，其余可选：

```
【文件夹名】todo-list
【类型】小项目（或：小文档）
【内容】一个待办事项页面：可以添加、勾选完成、删除待办，数据保存在浏览器本地
【备注】可选的额外要求，如技术偏好、参考风格等
```

各字段说明：

- **文件夹名**：新项目的文件夹名称，以你给出的为准（如需转成合法文件名会主动说明）。
- **类型**：二选一——`小文档`（Markdown 说明 / HTML 演示页）或 `小项目`（可运行的页面）。
- **内容**：想实现的功能或想写的内容，自由描述，无需拘泥格式。
- **备注**：可选。未提供的项一律按下方「约定」中的默认规则处理。

## 工作流程

1. **用户发起**：用户按上述格式指定新项目的**文件夹名**和**内容要求**。
2. **创建文件夹**：在 `Basic/` 目录下新建一个同名文件夹。
3. **生成内容**：
   - **小文档**：Markdown 文档，或带演示效果的 HTML 说明页。
   - **小项目**：标准结构 `index.html` + `style.css` + `script.js`（按项目实际需要增减）。
4. **交付说明**：完成后告知用户创建了哪些文件、如何打开预览（直接双击 `index.html` 即可）。
5. **等待下一步**：等待用户指示——修改当前项目，或继续下一个新项目。

## 约定

- 文件夹名以用户指定的为准；未指定时使用英文短横线命名（如 `todo-list`）。
- 每个项目自包含、相互独立，默认不依赖外部 CDN（如需使用会提前说明）。
- 代码与文档中的注释、说明使用**中文**。
- 每个项目只做基础功能，保持简单清晰，方便学习参考。
- 每次新建项目后，更新下方「项目索引」。
